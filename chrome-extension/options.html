BriskRead Options

Reader and developer preferences

What is this page?

The extension's Options page stores advanced connection settings. You do not need to change them to read. Right-click selected text or a page and choose Speed read this page to open the local reader.

Gemini API key

AI summary and document chat call Google directly with your own key. It is stored in this browser's extension storage and never sent to BriskRead. Get a free key ↗

Developer endpoints

Production defaults point at the live BriskRead app. Change only for local development.

Privacy

Article text is extracted and read locally in the extension. The website opens only when you explicitly choose Open BriskRead app. License keys stay in extension storage. See privacy policy.
